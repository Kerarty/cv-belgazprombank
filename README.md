# cv-belgazprombank — интерактивное резюме-кейс

Резюме для вакансии **«Специалист управления внедрения и развития информационных систем»**
(ОАО «Белгазпромбанк», Минск). Вместо перечисления навыков кандидат предлагает HR пройти
его рабочий цикл руками — за 5 минут.

**Онлайн:** https://kerarty.github.io/cv-belgazprombank/

## 1. Введение

- **Назначение** — продемонстрировать обязанности вакансии в действии: сбор требований,
  классификация, артефакты системного анализа, приёмочное тестирование поставки.
- **Аудитория** — HR и нанимающий менеджер департамента ИТ.
- **Формат** — одностраничное web-приложение, RU, печать в PDF из браузера.

## 2. Функциональные требования

| ID | Требование |
|----|------------|
| ФТ-1 | Кейс #BPB-2026-11 из 5 стадий: интервью → классификация → артефакты → приёмка → итоги |
| ФТ-2 | Интервью с бюджетом вопросов: ответы вскрывают требования не полностью (приоритизация) |
| ФТ-3 | Классификация карточек ФТ/НФТ/Ограничения: drag-n-drop + клавиатурный фолбэк |
| ФТ-4 | Артефакты: SRS-фрагмент, блок-схема «до/после», sequence-диаграмма REST⇄SOAP, Swagger |
| ФТ-5 | Приёмка поставки: вердикты по сценариям + указание нарушенного требования |
| ФТ-6 | Итоги: баллы, связка стадий с обязанностями вакансии, сброс кейса (`#reset`) |
| ФТ-7 | Сайдбар-резюме: образование, проекты с доказательствами, матрица навыков, контакты |

## 3. Нефункциональные требования

| ID | Требование |
|----|------------|
| НФТ-1 | Без бэкенда и внешних запросов: статика, состояние в `localStorage` |
| НФТ-2 | Печать в PDF (`window.print()` + print-стили: интерактив скрывается, контент остаётся) |
| НФТ-3 | `prefers-reduced-motion`, `:focus-visible`, aria-роли на интерактивных элементах |
| НФТ-4 | Мобильная ширина без горизонтального переполнения (проверено на 390px) |

## 4. Ограничения и допущения

- Кейс вымышленный, но повторяет структуру обязанностей вакансии.
- Данные кандидата — в `src/data/profile.ts`; контакты перед отправкой работодателю заполнить.
- Стек: TypeScript + Vite, без фреймворков; стили — один CSS-файл с переменными.

## 5. Архитектура

```
src/
├── main.ts               # хедер, каркас «кейс + сайдбар», футер
├── core/
│   ├── dom.ts            # минимальный DOM-хелпер (attrs/on*/children)
│   └── state.ts          # состояние кейса + localStorage + pub/sub
├── data/
│   ├── case.ts           # контент кейса: вопросы, требования, сценарии приёмки
│   └── profile.ts        # кандидат: проекты, навыки, контакты
├── stages/
│   ├── index.ts          # пайплайн стадий + перерисовка
│   ├── interview.ts      # стадия 1 · интервью
│   ├── classify.ts       # стадия 2 · классификация
│   ├── artifacts.ts      # стадия 3 · SRS / процесс / интеграция / Swagger
│   ├── acceptance.ts     # стадия 4 · приёмочное тестирование
│   └── results.ts        # стадия 5 · итоги
├── diagrams/
│   ├── sequence.ts       # SVG sequence-диаграмма (REST/SOAP)
│   └── flowchart.ts      # SVG блок-схема «как есть / как будет»
├── sections/sidebar.ts   # секции резюме
├── highlight.ts          # подсветка JSON/XML/YAML
└── styles/main.css       # дизайн-система + print
```

## 6. Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # dist/
npm run preview
```

### Docker

```bash
docker compose up --build   # http://localhost:8080
```

### Сброс прогресса кейса

Добавьте `#reset` к адресу или нажмите «Пройти кейс заново» на стадии итогов.

## 7. Связь навыков с вакансией

| Обязанность вакансии | Где показано |
|---|---|
| Сбор и формализация бизнес-требований | Стадия 1: интервью с заказчиком |
| Системные требования и программные решения | Стадия 2: классификация ФТ/НФТ/ОГР |
| Документация СА (ФТ, спецификации) | Стадия 3: SRS, блок-схема, Swagger |
| Протоколы и форматы обмена (HTTP, SOAP, JSON, XML, REST) | Стадия 3: sequence-диаграмма REST⇄SOAP с payload |
| Приёмочное тестирование, оценка качества ПО | Стадия 4: сценарии + дефекты против SRS |
| Взаимодействие с поставщиком ПО | Кейс целиком: заказчик + внешний шлюз |
| Docker, Linux | Этот репозиторий: Dockerfile, docker-compose |
| СУБД | Курсовой проект в сайдбаре (MySQL, JDBC, DAO) |
